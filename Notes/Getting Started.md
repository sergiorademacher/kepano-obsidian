# Getting Started with This Vault

Welcome! This checklist helps you set up and understand the vault.

## Initial Setup

- [ ] Open this vault in Obsidian
- [ ] Review Settings → Files & Links (attachments go to `Attachments/`)
- [ ] Review Settings → Templates (templates are in `Templates/`)
- [ ] Review Settings → Daily Notes (creates in `Daily/` with template)
- [ ] Set up the unique note hotkey for quick capture (Settings → Hotkeys → "Unique note")

## Understand the Structure

- [ ] Read [[Vault Methodology Guide]] - explains the philosophy
- [ ] Read [[Templates and Bases Reference]] - documents all templates and bases
- [ ] Browse the `Categories/` folder - see how collections work
- [ ] Browse the `Templates/` folder - see available note types
- [ ] Look at `Templates/Bases/` - see how database views work

## Try the Core Workflows

### Quick Capture (Fleeting Notes)
- [ ] Press your unique note hotkey (creates timestamped note)
- [ ] Write a quick thought
- [ ] Check [[Journal]] category to see it listed

### Daily Notes
- [ ] Use Cmd/Ctrl+P → "Open today's daily note"
- [ ] Write something in your daily note
- [ ] Notice how it embeds related notes via `![[Daily.base]]`

### Create a Reference Note
- [ ] Create a new note using the Book, Movie, or People template
- [ ] Fill in the properties
- [ ] Check the corresponding category page to see it listed

### Link Ideas Together
- [ ] In any note, type `[[` to create a link
- [ ] Link to people, topics, or other notes
- [ ] Check the backlinks panel to see connections

## Customize for Your Needs

- [ ] Decide which categories you'll use
- [ ] Delete templates you won't need (optional)
- [ ] Create your first [[Topics|topic]] notes for subjects you care about
- [ ] Set up any additional templates you need

## Key Concepts to Remember

| Concept | Meaning |
|---------|---------|
| **Categories** | What a note IS (Book, Movie, Meeting) |
| **Topics** | What a note is ABOUT (AI, Philosophy) |
| **Tags** | Status or special markers (to-read, 0🌲) |
| **Bases** | Database views that filter and display notes |

## Keyboard Shortcuts to Learn

| Action | Default Shortcut |
|--------|------------------|
| Open daily note | Cmd/Ctrl+P → "daily" |
| Create unique note | (set your own) |
| Open quick switcher | Cmd/Ctrl+O |
| Search vault | Cmd/Ctrl+Shift+F |
| Insert template | Cmd/Ctrl+P → "template" |

## Next Steps

Once comfortable with the basics:
- [ ] Explore the `Related.base` - embed in notes to find connections
- [ ] Try the `Backlinks.base` - see what links to a note
- [ ] Create your own category if needed
- [ ] Build your personal knowledge graph!
